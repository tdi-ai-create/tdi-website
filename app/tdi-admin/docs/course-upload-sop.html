Course Video & PDF Upload SOP

How to upload videos and documents to Learning Hub courses

Last updated: August 13, 2026

How It Works

Videos upload directly to Cloudflare Stream using the tus resumable protocol. No file size limit (up to 2GB). Uploads happen in 50MB chunks with automatic retry if your connection drops.

PDFs and documents upload directly to Supabase Storage via signed URLs. Max 25MB per file.

Uploading Videos

Option 1: Individual Upload (recommended for single lessons)

  1. Go to Learning Hub > Production > Courses
  2. Click on the course you want to edit
  3. Click on a lesson in the sidebar (lessons with red dots need videos)
  4. In the "VIDEO CONTENT" section, click "Click to upload video" or drag a file onto the drop zone
  5. Wait for the upload to complete. You'll see progress, speed, and time remaining.
  6. Once Cloudflare finishes processing (30-60 seconds after upload), the video player will appear
  7. Click Save Lesson

Option 2: Bulk Upload Videos

  1. Click the "Bulk Upload Videos" button below the course content list
  2. Drag and drop multiple video files (or click to select)
  3. The system auto-matches filenames to lesson titles. Review and adjust if needed.
  4. Click "Start Upload". Files process sequentially.
  5. Each file shows its own progress bar. Green = done, red = error.

Option 3: Bulk Upload Content (Mixed videos + PDFs)

  1. Click the "Bulk Upload Content" button
  2. Drop both video files AND PDF/document files together
  3. The system detects file types and routes them to the correct storage
  4. Review the auto-matching and click "Upload All"

Option 4: Google Drive

  1. Click the "Google Drive" button in the lesson editor
  2. Select a video from your Drive
  3. The file downloads and uploads to Cloudflare automatically

Accepted video formats: MP4, MOV, MKV, WebM

Max file size: 500MB per video (shown next to upload buttons)

Upload method: Videos upload to our storage first, then Cloudflare pulls them for processing. You never connect directly to Cloudflare.

Processing: Cloudflare transcodes after pulling the video. Takes 1-3 minutes for most videos. The player will show "Preparing your video..." during this time.

Uploading PDFs & Documents

Individual Upload

  1. Click on a lesson in the sidebar
  2. Scroll to the resource upload section
  3. Click the drop zone or drag a file in
  4. The file uploads directly to Supabase Storage (bypasses our server)
  5. Click Save Lesson

Bulk Upload

  1. Use the "Bulk Upload Content" button
  2. Drop PDF/Word/PPT/Excel files along with videos if needed
  3. Documents show a red file icon; videos show a blue play icon

Accepted document formats: PDF, Word (doc/docx), PowerPoint (ppt/pptx), Excel (xls/xlsx), PNG, JPG

Max file size: 25MB per document

Storage: Supabase Storage (lesson-resources bucket)

Generating Transcripts

Uploading the video is not the last step. A lesson without a transcript cannot carry a check-in, and a course whose lessons have no transcripts cannot be published. Generate transcripts as soon as the videos are in.

  1. Go to Learning Hub > Production > Courses
  2. Find the course in the list
  3. Click Generate transcripts
  4. Cloudflare produces captions for each video. Allow a few minutes for a long course.

Why it matters: transcripts do three jobs. They make lessons accessible to educators who need captions, they let learners download and reread the lesson, and they are the source material the check-in generator reads to write a question about that specific lesson.

What to check

  • Every teaching lesson has a transcript, not just most of them.
  • The final lesson of the course has one. If the last lesson is a short outro with almost no speech, the course's final check-in gets pushed to an earlier lesson.
  • A transcript of only a sentence or two counts as missing. It is not enough to write a real question from.

Known blockers as of August 2026: crack-the-co-teaching-code and escape-the-first-week have no transcripts at all and cannot be published. classroom-management-toolkit has a Wrap Up lesson with a transcript too short to use.

Once transcripts exist, see the Course Check-Ins SOP for creating the check-ins themselves.

Troubleshooting

Upload seems stuck or fails

  • Check your internet connection. The tus protocol auto-retries, but if your connection is completely down, it will eventually fail.
  • Try refreshing the page (Cmd+Shift+R for hard refresh) and uploading again.
  • Check file size. Videos must be under 2GB. Documents must be under 25MB.
  • Check file format. Only video files (MP4, MOV, MKV, WebM) work for video lessons.

Video shows "processing" for a long time

Cloudflare usually processes videos in 30-60 seconds. For very long videos (1+ hours), it can take a few minutes. If it's been more than 5 minutes, try refreshing the page. The video may already be ready.

Video uploaded but lesson still shows red dot

Make sure you clicked Save Lesson after the upload. The video_id needs to be saved to the lesson record.

Error: "Cloudflare Stream error" or "Failed to initialize upload"

This means Cloudflare's API had an issue. Wait a minute and try again. If it persists, check the diagnostic endpoint: /api/tdi-admin/videos/diagnostic

Diagnostic Check

If uploads aren't working, visit /api/tdi-admin/videos/diagnostic in your browser. It checks:

  • Whether the Cloudflare API token is valid
  • Current storage usage (minutes used vs limit)
  • Whether new upload URLs can be created
